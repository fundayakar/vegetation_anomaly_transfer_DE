# Data package

The exact data used for the manuscript are retained in the archival reproducibility package and will be released with the versioned Zenodo DOI.

The archival package contains:

- 24 original Google Earth Engine CSV exports for 2001–2024;
- `germany_fixedLC_2001_2024_combined.csv`, the combined 13,824-row monthly input to the Python pipeline;
- the 2,688-row April–October 2017–2024 model-ready table generated by the pipeline;
- the 2001–2016 reference statistics;
- complete fold-level output tables and manuscript figures.

Each yearly Earth Engine export contains 576 state × month × fixed-land-cover records (16 German federal states × 12 months × 3 broad vegetation classes). The validated extraction workflow is `../code/final_fixedLC_MOD13A3_ERA5_export.js`.

The combined modelling input has the following fields:

- `year`, `month`: calendar year and month
- `adm1`: German federal state (FAO GAUL ADM1 name)
- `lc_class`, `lc_name`: fixed broad land-cover class (forest, cropland, grassland)
- `ndvi`: fraction-weighted MOD13A3 monthly NDVI mean
- `temp_c`: fraction-weighted ERA5-Land 2-m air temperature (°C)
- `soil_moisture`: fraction-weighted ERA5-Land volumetric soil water content, layer 1 (0–7 cm)
- `precip_mm`: fraction-weighted ERA5-Land monthly precipitation (mm)
- `ndvi_n`: valid MOD13A3 support diagnostic
- `lc_weight_sum`: summed fixed land-cover fraction over valid support
- `lc_fraction_mean`: mean fixed land-cover fraction over valid support
- `lc_area_km2`: effective fraction-weighted class area over valid support

After downloading the archival data package, place the yearly files in `data/yearly_exports/`. They can be combined with `code/combine_yearly_exports.py` and checked against the archived combined input with `code/validate_final_gee_exports.py`.

All source products are public Earth-observation/reanalysis datasets; see the manuscript and main README for provenance and citations.
